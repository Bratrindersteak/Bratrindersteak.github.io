JS中的真值与假值

发表于2026-07-27|更新于2026-08-07|技术知识点
|总字数:196|阅读时长:1分钟

为什么会有真值、假值的概念存在？

因为 JavaScript 有【类型强制转换】的机制，在布尔值的上下文环境中（比如条件语句和循环语句就是布尔环境），非布尔类型的值会被强制转换为布尔值。

假值

假值（falsy，有时写为 falsey）是在布尔上下文中认定为 false 的值。

下列表格提供了 JavaScript 的所有假值：

值 类型 备注
false Boolean
null Null 空值
undefined Undefined 空值
NaN Number
-0 0 +0 Number
-0n 0n BigInt 没有+0n的语法
"" '' `` String
document.all HTMLAllCollection 标准已弃用，不建议使用

真值

真值（truthy）是在布尔上下文中认定为 true 的值。

除上述 8 种假值之外的其他任何值都属于真值。
